# GreenShift Full UI
Functional React/Vite prototype matching the supplied dark enterprise GreenShift reference.

Included:
1 Overview/Dashboard
2 Jobs
3 Submit Job
4 Region Selection
5 Carbon & Cost Information
6 Scheduling Decision Explanation
7 Baseline vs GreenShift
8 Job Monitoring
9 Audit & Trust
10 Alerts & Notifications

Intentionally excluded as requested:
Time Slot Recommendations, Kubernetes Execution Details, Carbon Savings Analytics,
Cost Savings Analytics, Region Analytics, Historical Trends, Failure/No Feasible Slot Handling.

Run: npm install && npm run dev
